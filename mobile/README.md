# 📱 AgroGrowth Native Mobile Application

> **تطبيق AgroGrowth الفلاحي الذكي للهواتف المحمولة (Android & iOS)**  
> مبني باستخدام **React Native** و **Expo SDK 58** بالاعتماد الكامل على بنية Express API و Supabase ونماذج الذكاء الاصطناعي الزراعية التونسية.

---

## 🌟 رؤية المنتج والتجربة المحمولة (Mobile-First UX)

تم تصميم هذا التطبيق ليكون رفيقاً يومياً عملياً وسهل الاستخدام للفلاحين والمهندسين الزراعيين في الحقل:
1. **أولوية البساطة والوضوح:** أزرار كبيرة وعريضة (Touch Targets ≥ 48dp)، خطوط عربية واضحة، بدون مصطلحات معقدة.
2. **الواجهة العربية أولاً مع دعم RTL كامل:** ودعم التبديل الفوري للغتين الفرنسية والإنجليزية.
3. **أقل عدد من الخطوات:** إجراء الفحوصات والتشخيصات بنقرة واحدة (1-Tap Quick Actions).
4. **الشفافية في مصدر البيانات (Honest Data Provenance):** يوضح التطبيق للمستخدم ما إذا كان التحليل صادراً عن فحص حي، أم نموذج رؤية حاسوبية، أم دليل إرشادي زراعي معتمد.
5. **العمل في وضع عدم الاتصال (Offline Support):** تخزين مؤقت للطقس والمهام والحقول لتصفحها في المناطق الريفية ضعيفة التغطية.

## 🧭 البنية والتنقل الرئيسي (Bottom Navigation)

1. **الرئيسية (Home):**
   - تحية مخصصة بحسب اسم الفلاح وولايته (تونس، باجة، القيروان، سوسة، صفاقس، قبلي...).
   - بطاقة حالة الطقس المباشرة من محطات الرصد الجوي (درجة الحرارة، الرطوبة، فرصة الأمطار، سرعة الرياح، والنصيحة الزراعية لليوم).
   - شريط التنبيهات العاجلة (الرياح الحارة، خطر الصقيع، تنبيهات نشاط الفطريات).
   - إجراءات سريعة بنقرة واحدة:
     - 📸 فحص النباتات بالصورة (كشف الأمراض الفطرية والحشرية).
     - 🧪 فحص وتحليل التربة (تقييم الخصوبة وبرنامج التسميد).
     - 🌾 توصيات المحاصيل (المحاصيل الأكثر ملاءمة وربحية).
     - 💰 أسعار السوق اليوم (أسعار الجملة المحدثة).
     - 💧 جدولة الري الذكي (ترشيد المياه).
   - بطاقة الوصول السريع للمستشار الزراعي الذكي.
   - قائمة مهام اليوم الموصى بها مع إمكانية التأشير على المنجز منها.

2. **الخدمات (Services):**
   - دليل شامل ومصنف لكافة خدمات منصة AgroGrowth:
     - **التربة والمحاصيل:** تحليل التربة، مقارنة التربة المثالية، اقتراح المحاصيل، الدورة الزراعية.
     - **صحة النبات والوقاية:** كاشف أمراض النبات بالصورة، مكافحة الآفات، جداول الرش.
     - **الري والمناخ:** الري الذكي، الطقس الزراعي، تحليلات توفير المياه.
     - **إدارة المزرعة والمالية:** تسجيل الحقول، متابعة الثروة الحيوانية، تتبع المصروفات.
     - **المجتمع والاستشارات:** استشارة الخبراء الزراعيين والبياطرة، منتدى الفلاحين.

3. **المساعد الذكي (AI Assistant):**
   - مستشار زراعي تفاعلي يفهم اللهجة التونسية والعربية الفصحى والفرنسية والإنجليزية.
   - أزرار اقتراحات سريعة لأسئلة شائعة (ري الزيتون، أمراض الطماطم، تسميد القمح، أسعار السوق).
   - مدعوم بقاعدة المعرفة الزراعية التونسية ونماذج الرؤية الحاسوبية.

4. **السوق والأسعار (Marketplace):**
   - أسعار الجملة المحدثة للسلع الزراعية في تونس (بالدينار التونسي د.ت / كغ).
   - تتبع مسار الأسعار (ارتفاع، انخفاض، استقرار) ونسب التغير.
   - تصنيفات الجودة ومواقع الأسواق (بئر القصعة، صفاقس، باجة، قبلي).

5. **الملف الشخصي (Profile):**
   - بطاقة بيانات الفلاح ومزرعته.
   - **مبدل الأدوار (Role Switcher):** تجربة التطبيق بكافة الأدوار الثمانية المعتمدة في المنصة (فلاح، خبير زراعي، طبيب بيطري، تاجر، مراقب حقول، مدير).
   - مبدل لغات فوري (العربية، Français, English).
   - أداة تشخيص الاتصال بالخادم وقاعدة بيانات Supabase.

## 🛠️ المتطلبات والتشغيل المحلي

### 1. تثبيت الحزم
تم تثبيت الحزم بالكامل. إذا أردت تثبيتها مجدداً:
```bash
cd mobile
npm install
```

### 2. تشغيل التطبيق
```bash
# تشغيل خادم التطوير مع Expo
npm start

# أو تشغيله مباشرة على Android
npm run android

# أو على iOS
npm run ios

# أو في المتصفح لتجربة الواجهة فوراً
npm run web
```

## 🌐 الاتصال بالخادم والخدمات السحابية

- **خادم Express API:** متصل افتراضياً بـ `http://localhost:5000` (أو `http://10.0.2.2:5000` لمُحاكي أندرويد).
- **قاعدة بيانات Supabase:** `https://jymrhhlwdbclctobhbsi.supabase.co` عبر `@supabase/supabase-js` و `expo-secure-store`.
- **محطات الطقس:** متصل مباشرة بـ Open-Meteo المعتمد لنقاط الرصد التونسية.
